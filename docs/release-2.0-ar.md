# StuClub 2.0 — تقرير التنفيذ والتشغيل

التطبيق Android باستخدام Flutter وDart، بهوية اللوجو الأصلية: كحلي داكن وسماوي وأزرق وبنفسجي وفوشيا. لا يوجد حساب ولي أمر وفق طلب المستخدم.

## المنفذ محليًا
- الحسابات، المؤسسات والمدارس، التوثيق والإشراف، الصف وسنة الميلاد، وضوابط التواصل بحسب المؤسسة والصف والفئة العمرية وتكليف المعلم. هذه ضوابط أساسية وليست اعتمادًا جاهزًا لتشغيل مدرسة حقيقية.
- المواد والشعب وتسجيل الطلاب وتكليف المدرسين والمجموعات الرسمية.
- المنشورات والقصص بالصور والفيديو والتعليقات والإعجابات والمحادثات والأصدقاء والطلبات والحظر والإبلاغ.
- ملصقات رسومية فعلية داخل المحادثة، ومشاركة PDF وDOCX وTXT وحفظها باستخدام منتقي الملفات في Android.
- استطلاعات مع تعديل الاختيار وإغلاق التصويت؛ المستندات والاستطلاعات تراعي صلاحيات المؤسسة والشعبة.
- الإعلانات الرسمية وتقارير المشاهدة الفريدة ونسبة الفتح ومتوسط زمن أول مشاهدة المسجل؛ البيانات القديمة التي لا تحمل توقيتًا لا تحصل على توقيت مختلق. هذه تقارير تشغيل وليست دراسة علمية تثبت تحسنًا.
- XO محلية وعبر الخادم ودعوات لعب، بطولات دورية بنقاط، لعبة ذاكرة فعلية، سباق الحساب والاختبار التعليمي، تقويم النشاط والتجميد المكتسب.
- تخزين SQLite وترحيل JSON مع الحفاظ على نسخة، وأداة نسخ احتياطي للقاعدة والوسائط والمستندات وإعداد الإدارة.
- رموز تحقق البريد واستعادة الحساب صالحة مرة واحدة، لها انتهاء وحد محاولات وطلبات. محليًا تُحفظ الرسائل في backend/data/outbox؛ لا يظهر الرمز في استجابة الشبكة. هذا مجلد خاص بالمشغل.

## ما يحتاج خدمة خارجية أو عملًا إضافيًا
- أُعد موصل SMTP وFCM وإعدادات نشر Docker وCaddy عبر HTTPS وبناء AAB موقّع. لم يتم إرسال بريد خارجي أو إشعار حقيقي أو نشر خادم أو رفع متجر، لعدم وجود حسابات الخدمة والنطاق والمفاتيح. لا تدخل أسرارًا في الشات.
- الغرف والمكالمات الصوتية الحية غير منفذة. لا يمثل زر أو محادثة نصية مكالمة صوتية.
- لا دفع أو إعلانات تجارية؛ تجميد النشاط مكافأة مكتسبة. لا توجد دراسة ميدانية أو قياسات قبل/بعد.
- التخزين يخدم عملية خادم واحدة؛ لا تشغل عدة نسخ خادم على القاعدة نفسها. النسخة المسلمة APK debug للتجربة وليست إصدار المتجر.

## التشغيل والنسخ
من مجلد المشروع شغّل Start-Local.ps1، ثم ثبّت APK على الهاتف المتصل. الإعداد المحلي يعتمد ربط USB إلى منفذ8080. استخدم Run-Debug.ps1 للتطوير مع تعطيل DDS الذي سبب مشكلة الاتصال السابقة.
إعداد المشرف: Configure-Admin.ps1 -Email <عنوان حساب موجود>؛ أعد تشغيل الخادم بعد التعديل. لا ينشئ السكربت حسابًا جديدًا.
النسخ: Backup-Local.ps1 يوقف الخادم ويحفظ نسخة خاصة ثم يعيد تشغيله. احتفظ بمجلد النسخة كاملًا؛ الاستعادة تتم والخادم متوقف بإرجاع القاعدة والوسائط والمستندات وإعداد operator إلى backend/data. لا تستبدل ملف قاعدة نشطة أو ملفات WAL أثناء التشغيل.

## تفعيل الخدمات والنشر
انسخ deploy/.env.example إلى ملف إعداد خاص خارج حزمة المصدر، واضبط النطاق والبريد الاختياري. SMTP يحتاج STU_MAIL_MODE=smtp وإعدادات STU_SMTP_* وSTU_MAIL_FROM. يستخدم TLS. لرسائل FCM يحتاج الخادم STU_FCM_PROJECT وGOOGLE_APPLICATION_CREDENTIALS لملف حساب الخدمة؛ لا تضع هذا الملف داخل التطبيق. راجع أسماء المتغيرات في ملف المثال.
إعداد Firebase للعميل يحتاج إعدادات عامة FIREBASE_API_KEY وFIREBASE_APP_ID وFIREBASE_PROJECT_ID وFIREBASE_SENDER_ID؛ التطبيق يطلب الإذن عند تفعيل التنبيهات من صفحة الخدمات. إعدادات الخادم السرية منفصلة تمامًا.
نفّذ نشر compose بعد ضبط النطاق وDNS وإعداد الخدمات. ملف compose جرى فحصه بنيويًا، ولم يُختبر نشره على استضافة فعلية.
لبناء المتجر استخدم Build-Release.ps1 -ApiUrl https://your-real-domain -CreateSigningKey ومعه -FirebaseConfig عند الحاجة. احفظ مفتاح التوقيع وإعداداته في مكان خاص؛ السكربت لا يستبدل مفتاحًا موجودًا. يتطلب جهاز البناء Flutter على PATH. يجب اختبار التشغيل عبر HTTPS والتوقيع والخدمات قبل نشر المتجر.

المراجع: [FCM HTTP v1](https://firebase.google.com/docs/cloud-messaging/send/v1-api)، [SQLite VACUUM INTO](https://www.sqlite.org/lang_vacuum.html)، [mailer](https://pub.dev/documentation/mailer/latest/mailer/).

## التحقق
اجتاز Flutter analyze، و17 اختبار Flutter و16 اختبار خادم. تغطي الاختبارات صلاحيات المدارس والمستندات والاستطلاعات والتقارير والذاكرة والبطولات والبريد المحلي وترحيل SQLite ورفض الكتابة المتعارضة. بُني APK Android بنجاح. اختبارات اختيار وحفظ الملفات تحاكي جسر Android؛ لا تعني تجربة يدوية كاملة لكل جهاز. تكامل SMTP وFCM والنشر الخارجي غير مختبر لغياب الحسابات. صور المعاينة بيانات اصطناعية معزولة عن حسابات المستخدم.
