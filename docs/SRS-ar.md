# StuClub — متطلبات النسخة المحلية 1.4 وخطة المنتج

المصدر: نص المحادثة الذي أرسله صاحب المشروع، اللوجو الأصلي، وصورتا قسم الألعاب والـStreak. تاريخ الوثيقة: 23 أكتوبر 2026.

## الهدف

جمع التواصل والترفيه والألعاب مع إعلانات المدرس والدكتور البارزة، بحيث يصل التحديث الأكاديمي إلى المكان الذي يفتحه الطالب يوميًا. يشمل نطاق المنتج المدارس والجامعات. لا تُستخدم أمثلة العرض التقديمي كإحصاءات بحثية.

## حدود النسخة الحالية

Android بـFlutter وDart وخادم Dart محلي. الحسابات الحالية ومعرّفات جامعاتها محفوظة. أضيفت مدرسة تجريبية معزولة، تتطلب اعتماد المشرف قبل قراءة محتواها. المدرسة نموذج اختبار محلي، وليست تشغيلًا جاهزًا لقُصّر أو مدارس حقيقية. أسماء الجامعات السابقة تبقى بيانات التجربة، ولا تمثل قائمة مؤسسات معتمدة.

## حدود يجب ألا تختلط بالإنجاز الحالي

- استهداف المادة والشعبة الرسمي يحتاج نموذج مقررات وتكليف مدرسين وقوائم تسجيل معتمدة. الاستهداف الحالي بالمجموعة لا يثبت القيد الأكاديمي؛ الانضمام للمجموعات ذاتي.
- إدارة مؤسسات حقيقية وأعمار الطلاب  وفصل فئات القُصّر داخل المؤسسة لم تكتمل. لا تُستخدم المدرسة التجريبية مع طلاب حقيقيين بهذه الحالة.
- طلب الصداقة كعلاقة مستقلة، اللعب الجماعي عبر الشبكة، دعوات التحدي والبطولات والغرف الصوتية لم تنفذ. XO محلية فقط.
- لا Push أو بريد أو إعلانات تجارية أو دفع؛ التجميد مكافأة نشاط محلية.
- لا ملفات PDF/مستندات أو استطلاعات بعد؛ الوسائط الحالية صور وفيديو.
- التخزين JSON لعملية واحدة، والخادم على loopback. النسخة APK debug وليست إصدار متجر.
- لا قياسات بحثية لزمن وصول الإعلان أو مقارنة قبل/بعد حتى الآن؛ عداد المشاهدة أساس أولي فقط.

## ترتيب الاستكمال

1. المقررات والشعب وتكليف المعلمين والعضوية المعتمدة من المشرف.
2. إدارة المدارس والأعمار وأدوار الإشراف وحماية التواصل بين الفئات.
3. علاقات الصداقة ودعوات اللعب وشبكة XO قبل إضافة عناوين ألعاب كثيرة.
4. حزم ملصقات مصورة ومشاركة المستندات والاستطلاعات.
5. إشعارات الهاتف والاستعادة البريدية والاستضافة عند توفير الخدمات.
6. استبيان وتجربة محدودة وقياس سرعة مشاهدة الإعلانات ونسبة فتحها والعودة اليومية، دون اختلاق نسب.

## التشغيل

يشغّل Start-Local.ps1 الخادم المحلي ويربط الجهاز المتصل. اعتماد المشرف يُضبط من Configure-Admin.ps1 بواسطة المشغل. الحساب التعليمي يطلب التوثيق من حسابي ثم يعتمده المشرف. يظهر زر نشر الإعلان أعلى الرئيسية للحساب المخول. المدرسة التجريبية تحتاج اعتماد الطالب أيضًا.

معاينات الصور بيانات اصطناعية معزولة؛ ظهور إعلان د. مريم أو سلسلة 7 أيام في الصور لا يعني إضافة هذه البيانات إلى الحسابات الحقيقية.
