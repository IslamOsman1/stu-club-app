## توثيق الوظائف والتشغيل من الإصدارات السابقة

# وظائف الإصدار السابق — Flutter / Dart

تطبيق Android عربي مع خادم Dart محلي. لا تحتاج النسخة الحالية إلى Firebase أو خدمة بريد. تحتاج تشغيل الخادم على الكمبيوتر أثناء الاستخدام.

## ما يعمل الآن

- إنشاء حساب ودخول وخروج، جلسات 7 أيام، كلمات مرور PBKDF2-HMAC-SHA256 بملح مستقل و210000 دورة، ورموز جلسات مشفرة باستخدام Android Keystore.
- ملف شخصي، تغيير كلمة المرور مع إلغاء كل الجلسات، حذف الحساب ومحتواه وملفاته من التخزين النشط.
- كود استعادة احتياطي يظهر مرة واحدة ويُستخدم مرة واحدة؛ إنشاء كود جديد يلغي القديم. الاستعادة بالبريد غير مفعلة.
- منشورات واستوريهات مع نص وصورة أو فيديو، إعجاب، تعليقات وحذف وإبلاغ. الاستوري تنتهي بعد 24 ساعة.
- ملفات JPG/PNG/WEBP/MP4 حتى 20 ميجابايت للملف، و150 ميجابايت إجماليًا لكل حساب. الخادم يفحص توقيع صيغة الملف، ويشترط المصادقة والجامعة عند تنزيله؛ الملفات غير المنشورة لصاحبها فقط.
- مجموعات الجامعة وشات المجموعة، ومحادثات خاصة بين زملاء الجامعة؛ تحديث الشات كل 4 ثوانٍ.
- حظر وإلغاء حظر؛ يمنع الرسائل ويخفي محتوى الطرفين والتعليقات بينهما.
- تنبيهات داخل التطبيق للإعجابات والتعليقات والرسائل ونتائج التوثيق. ليست إشعارات Push على الهاتف.
- عشرة أسئلة تعليمية؛ الإجابات والنقاط يراجعها ويحفظها الخادم. لعبة سباق حساب: 10 أسئلة عشوائية في 90 ثانية، مع احتساب مكافأة جولة واحدة يوميًا بتوقيت UTC.
- طلبات توثيق طالب أو دكتور، واعتماد أو رفض يدوي من المشرف. التوثيق ليس اتصالًا آليًا بالجامعة.
- لوحة مشرف لمراجعة البلاغات وحذف المحتوى المخالف، وإيقاف وتفعيل الحسابات، ومراجعة التوثيق. لا يمكن اختيار دور مشرف أو دكتور عند التسجيل.
- أيقونة STU Club خاصة بدل أيقونة Flutter.

## التشغيل من مجلد المشروع

1. وصّل هاتف Android عبر USB مع السماح بتصحيح USB، أو شغّل المحاكي.
2. شغّل `Start-Local.ps1`، ثم ثبّت APK الجديد.
3. أنشئ حسابًا أو سجّل بحسابك السابق. الخادم يحافظ على ملفات الإصدار السابق ويضيف الحقول الجديدة.
4. في المحاكي يُختار `http://10.0.2.2:8080` تلقائيًا عند عدم حفظ عنوان سابق. الهاتف يستخدم `http://127.0.0.1:8080` عبر adb reverse.
5. إذا انقطع USB، أعد تشغيل سكربت البدء لإعادة الربط. من إعداد اتصال الخادم يمكن تغيير العنوان يدويًا؛ تغيير الخادم يسجل خروجك.

لا تشغّل خادمين على ملف البيانات نفسه. استخدم `Stop-Local.ps1` لإيقاف خادم المشروع قبل استخدام الخادم المستقل.

## تفعيل المشرف المحلي

أنشئ حسابك العادي أولًا. من PowerShell داخل مجلد المشروع شغّل:

`./Configure-Admin.ps1 -Email 'your-account@example.com'`

ثم أوقف الخادم وأعد تشغيله، وسجّل الدخول من جديد. ستظهر لوحة المشرف في حسابي. هذا الإعداد يمنح الحساب الوصول إلى إدارة المجتمعات كلها؛ لا تعيّن بريد شخص آخر بالخطأ.

لإلزام الحسابات غير الموثقة بالحصول على اعتماد قبل الوصول لمحتوى الجامعة:

`./Configure-Admin.ps1 -Email 'your-account@example.com' -RequireVerification`

ثم أعد تشغيل الخادم. يظل المستخدم غير الموثق قادرًا على تسجيل الدخول وإرسال طلب توثيق وإدارة حسابه، لكنه لا يستطيع قراءة أو نشر محتوى الجامعة حتى الاعتماد. هذا الوضع غير مفعل افتراضيًا لتسهيل التجربة المحلية.

الإعداد محفوظ في `backend/data/operator.json`. لا تنشره أو تعدله عبر واجهة المستخدم. المشرف يجب أن يتحقق فعليًا من الانتماء الجامعي والصفة خارج التطبيق قبل الموافقة. الاعتماد اليدوي لا يرسل بريدًا ولا يتصل بأنظمة الجامعات.

## الاستعادة والخصوصية

قبل نسيان كلمة المرور: حسابي ← الحساب والخصوصية ← إنشاء كود استعادة الحساب. احفظ الكود خارج التطبيق. عند الحاجة: شاشة الدخول ← نسيت كلمة المرور؟ استخدم كود الاستعادة. لا يوجد إرسال بريد. الحساب الذي لم ينشئ كودًا لا يمكنه استخدام هذه الطريقة.

حذف الحساب يحذف البيانات والوسائط الخاصة به من قاعدة الخادم النشطة، والمحادثات التي يكون طرفًا فيها. النسخ الاحتياطية التي يصنعها مشغّل الكمبيوتر يدويًا منفصلة ويجب أن يدير احتفاظها وحذفها بنفسه.

## اختبارات وبناء

- من الجذر: `flutter analyze` ثم `flutter test` ثم `flutter build apk --debug`.
- من backend: `dart analyze` ثم `dart test`.
- الاختبارات تغطي صلاحيات الجامعات وملكية المحتوى والشات والحظر، التوثيق والإيقاف والمراجعة، استعادة الحساب وإلغاء الجلسات، حذف الحساب، حماية الوسائط وحذفها، انتهاء الاستوري، وعدم تكرار نقاط الاختبارات واللعبة.

## حدود التشغيل المحلي

الخادم يستمع إلى loopback فقط، والاتصال HTTP مسموح في debug للتجربة. النشر العام يحتاج HTTPS واستضافة وقاعدة بيانات مناسبة ونسخًا احتياطيًا ومراقبة وضبط معدلات الطلبات ومراجعة أمان. التخزين الحالي JSON لعملية خادم واحدة وحجم تجربة صغير. الرسائل ليست مشفرة من طرف إلى طرف؛ يستطيع مشغّل الخادم والمشرف مراجعة المحتوى المبلغ عنه.

لا توجد إشعارات Push، استعادة بريدية، مكالمات، تكامل آلي مع الجامعة أو متجر Play. APK نسخة debug محلية؛ توقيع الإصدار النهائي والنشر على المتجر منفصلان. اختبارات الواجهة والخادم لا تغني عن اختبار استخدام كامل على أجهزة فعلية، خصوصًا منتقي الصور وترميز الفيديو.

## التصميم في 1.3

واجهات جديدة بألوان أخضر وكريمي، خط عربي مضمّن يعمل بدون اتصال، رسم جامعي أصلي، بطاقات وتصفح أوضح، وحالات فارغة مفهومة. الرسائل الخاصة وشات المجموعات يستخدمان فقاعات محادثة مع تمييز رسائلك. أضيف البحث في المنشورات والمجموعات والزملاء وفلتر منشورات الدكاترة، وإظهار وإخفاء كلمة المرور. جرى فحص التصميم بمقاس 414×896، وبشاشة 320×740، ومع تكبير الخط 130%.

معاينات التصميم تستخدم بيانات تجريبية معزولة، ولا تضاف هذه البيانات لحسابات المستخدمين. خادم 1.2 متوافق مع نسخة Android 1.3.

خط Cairo مصدره مستودع Google Fonts الرسمي: https://github.com/google/fonts/tree/main/ofl/cairo . ترخيص OFL محفوظ في assets/fonts/OFL.txt. الرسم الجامعي والأيقونة من ملفات المشروع.

## إصلاح الاتصال 1.3.1

يفحص التطبيق هوية خادم STU Club قبل إرسال بيانات تسجيل الدخول. على المحاكي فقط، يمكنه اختبار العنوانين المحليين 10.0.2.2 و127.0.0.1 على المنفذ 8080؛ لا يغير عنوانًا مخصصًا إلى خادم آخر. فحص الصحة لا يرسل رمز جلسة أو كلمة مرور، ولا تُعاد محاولة طلبات التسجيل تلقائيًا. أضيف زر فحص الاتصال في رسالة الخطأ وإعداد اتصال يعرض نجاح الفحص قبل اعتماد العنوان. مهلة استجابة عمليات الحساب أصبحت 60 ثانية لاستيعاب اشتقاق كلمة المرور على الأجهزة الأبطأ، ورسائل الأخطاء تميز التأخير والانقطاع والاستجابة غير الصحيحة.

اختبار الجهاز في integration_test/connection_test.dart يحتاج خادمًا منفصلًا على المنفذ 18083 ببيانات تجريبية. لا تشغّله على بيانات حقيقية. عند استخدام flutter test لاختبارات الأجهزة استخدم --no-uninstall للحفاظ على بيانات التطبيق المحلية. في نسخة Flutter الحالية ظهر خطأ تهيئة في قناة VmServiceProxyGoldenFileComparator رغم أن جسم اختبار التسجيل والدخول اكتمل بنجاح على الجهاز خلال 11 ثانية. سجل المشغّل الإجمالي لم يكن ناجحًا؛ اختبارات flutter test العادية وفحص flutter analyze نجحت.

## Windows debug connection workaround

On this machine Flutter DDS can fail with a localhost WebSocket connection refusal after a successful APK install. Use `./Run-Debug.ps1` (optionally `-Device emulator-5554`) to prepare the local server and start `flutter run --no-dds`. Direct Dart VM service connection and hot reload have both been verified. VS Code also includes the `StuClub Android (direct debugger)` launch configuration. This changes only this project's debug launch; no global SDK settings or security protections are changed. The engine-flags migration notice is informational and is separate from the DDS connection failure.
